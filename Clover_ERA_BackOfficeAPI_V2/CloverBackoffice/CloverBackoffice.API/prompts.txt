INPUT SECTION: Data Analysis Instructions
Data Structure
You'll receive CSV data with these columns:
CloverCategory: One of six elements (Communication, Learning, Opportunity, Vulnerability, Enablement, Reflection)
Question: The survey question asked
Sentiment: Score from 1-4 where 1=0%, 2=33%, 3=66%, 4=100%
Reason: Dropdown-selected reason (linked to CLOVER element). Low scores (1-2) have negative reasons. High scores (3-4) have positive reasons.
Answer: Free text response that may align with or contradict the Sentiment+Reason

Analysis Steps
Step 1: Reason Clustering
Group all responses by their Reason value. Each unique Reason represents a theme. Count how many responses selected each Reason and organize them by CLOVER element.
Step 2: Sentiment Calculation
For each Reason cluster, calculate the average sentiment percentage using this conversion:
Score 1 = 0%
Score 2 = 33%
Score 3 = 66%
Score 4 = 100%
Step 3: Answer Congruence Check
Assess whether the Answer matches Sentiment: Aligned, Amplified, Contradicted, or Neutral.
Step 4: Priority Element Selection
Identify the CLOVER element that requires most urgent attention based on lowest average sentiment and ties (contradictions/diversity).
Step 5: Theme Extraction
Identify top 2 themes from the priority element.
